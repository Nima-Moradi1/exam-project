# آزمون جامع HTML فارسی

یک برنامهٔ کامل آزمون HTML با Next.js App Router، TypeScript و Tailwind CSS. رابط کاربری کاملاً فارسی و راست‌به‌چپ است و تصحیح پاسخ‌ها فقط در Route Handler سمت سرور انجام می‌شود.

## قابلیت‌ها

- دقیقاً ۳۰ پرسش: ۳ پاسخ کوتاه، ۱۰ کشویی، ۱۲ چهارگزینه‌ای و ۵ درست/نادرست
- ذخیرهٔ خودکار پاسخ‌ها و موقعیت فعلی در مرورگر
- حالت روشن و تاریک با رعایت تنظیم سیستم
- ناوبری کامل، نمایش پیشرفت و هشدار خروج از زبانه
- ثبت نهایی با تأیید کاربر و قفل‌کردن تلاش ثبت‌شده
- نتیجهٔ کامل و پاسخ‌نامهٔ تشریحی واکنش‌گرا
- اعتبارسنجی سخت‌گیرانه با Zod و کلید پاسخ `server-only`
- تست‌های واحد و مرورگر برای ساختار، ارزیابی، امنیت API و جریان اصلی

موضوعات پرسش‌ها با الهام از سرفصل‌های دورهٔ [آموزش HTML راکت](https://roocket.ir/series/learn-html/) انتخاب شده‌اند؛ متن همهٔ پرسش‌ها و توضیح‌ها برای این پروژه از نو نوشته شده است.

## اجرا

به Node.js نسخهٔ 20.9 یا جدیدتر نیاز است.

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## بررسی کیفیت

```bash
npm run lint
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

هیچ متغیر محیطی برای اجرای برنامه لازم نیست. برای استقرار، همین مخزن را مستقیماً به Vercel متصل کنید.

## معماری امنیتی

دادهٔ عمومی پرسش‌ها در `lib/questions/public.ts` نگهداری می‌شود. کلید پاسخ، سطح دشواری و توضیح‌ها در ماژول‌های دارای `server-only` هستند و کامپوننت‌های کلاینت آن‌ها را import نمی‌کنند. مسیر `POST /api/submit` داده را اعتبارسنجی و سپس روی سرور ارزیابی می‌کند. پاسخ‌های صحیح فقط پس از ثبت نهایی و در قالب مرور همان تلاش برگردانده می‌شوند.

محدودیت‌های انتخاب متن، منوی راست‌کلیک و میانبرها صرفاً بازدارنده‌های معقول‌اند؛ مرورگر در کنترل کاربر است و جلوگیری مطلق از مشاهده یا خودکارسازی ممکن نیست.
